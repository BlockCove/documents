以太坊 L1、L2、侧链技术详解报告

1. 概念总览

以太坊生态中，L1 是底层基础账本，L2 与侧链是两类主要扩容方案，三者的安全模型、运行层级、风险完全不同：

  • L1（一层）：以太坊主网，底层结算层，安全最高，性能差、gas高。
  • L2（二层）：构建于L1之上，链下计算，链上结算，继承L1安全性。
  • 侧链 Sidechain：独立区块链，自有共识，通过桥与以太坊互通，不继承L1安全。

扩容背景

受「不可能三角」制约，以太坊 L1 优先保障去中心化与安全，性能受限：TPS 仅约 15，网络拥堵时一笔转账的 Gas 费可达数十美元，无法承载海量高频用户。L2 通过链下计算将 TPS 提升至数千量级、手续费可降低一个数量级；侧链则以不继承以太坊安全为代价换取更高性能。

2. L1 以太坊一层主网

什么是L1

L1就是以太坊主网，整个生态的底层基础账本，所有资产的最终确权、最终结算发生在这里。L2 的验证合约、侧链的桥合约也都部署在 L1 上。

解决什么问题

实现去中心化可信账本、智能合约执行、无需中介的价值转移，保障资产不可篡改。

核心原理

  • 采用 PoS 权益证明共识，全网验证节点共同确认区块（出块时间约 12 秒）。
  • 每笔交易被全网节点验证、执行、写入账本。
  • 所有状态最终以L1账本为准。

痛点

为了去中心化安全牺牲性能：TPS 仅约 15，拥堵时Gas手续费高昂，不适合海量高频用户。这催生L2与侧链扩容。

3. L2 二层扩容（Rollup）

什么是L2

L2运行在L1之上，大量计算、交易在L2执行，只把压缩后的批量交易数据（ZK-Rollup 同时附带有效性证明）提交L1完成最终结算。安全继承以太坊L1。

解决什么问题

解决L1吞吐量低、手续费贵，在不牺牲底层安全前提下提升TPS，支撑DeFi、NFT、游戏高频交互。

核心原理：链下计算，链上结算

sequenceDiagram participant User as 用户 participant L2 as L2 Rollup节点 participant L1 as 以太坊L1合约 User->>L2: 发送多笔交易（转账、合约调用） L2->>L2: 在L2本地执行全部交易，更新L2状态 L2->>L2: 将多笔交易批量压缩（ZK同时生成有效性证明） L2->>L1: 将批量数据（ZK附有效性证明）提交上L1 L1->>L1: L1合约结算：校验证明 / 等待挑战期 Note over L1: ZK：证明校验通过即获最终性；Optimistic：约7天挑战期，靠欺诈证明纠错 User->>L1: 提现：通过L1合约取回资产（Optimistic需等挑战期结束）

提现周期差异：Optimistic-Rollup 提现需等待约 7 天挑战期（第三方快速桥可缩短体验）；ZK-Rollup 数十分钟至数小时即可到账。

两类主流Rollup

  • ZK-Rollup：提交批次时附带零知识有效性证明，L1 合约直接验证，最终性快、提现快。代表：ZKsync Era、Starknet、Scroll。
  • Optimistic-Rollup：乐观假设交易有效，先上链、后挑战，靠欺诈证明纠错，存在约 7 天挑战窗口，提现周期长但 EVM 兼容、生态成熟。代表：Arbitrum、Base、OP Mainnet（原 Optimism）。

其他变体：Validium（交易数据存链下，成本更低但数据可用性不依赖 L1）、Plasma（数据几乎全在链下，安全模型更弱）。当前主流仍是 ZK 与 Optimistic 两类。

数据可用性与成本优化

Rollup 必须把批量交易数据发布到 L1，保证数据可用性——任何人都能依据链上数据重建 L2 状态。自 2024 年 Cancun 升级（EIP-4844）起，数据以 blob 形式存储，成本显著低于普通 calldata，L2 手续费因此进一步下降。

4. 侧链 Sidechain

什么是侧链

侧链是一条完整独立区块链，拥有自己的节点、共识算法（如 Polygon PoS、Ronin 采用 PoS 类共识，BSC 采用 PoSA）。通过双向跨链桥和以太坊做资产映射，与L1是平行关系，不属于L2。

解决什么问题

获得极高TPS、极低手续费，链规则可自定义，适合游戏、小额高频场景。

工作原理：双向锚定跨链桥

flowchart LR U[用户] subgraph L1["以太坊L1"] B1[桥合约：锁定ETH/ERC20] end subgraph SC["侧链 独立链"] B2[侧链桥合约] SC_consensus[侧链自有共识节点] end U -->|充值：L1锁定资产| B1 B1 -->|桥通知| B2 B2 -->|在侧链铸造映射资产| U U -->|提现：销毁侧链映射币| B2 B2 -->|触发| B1 B1 -->|L1释放原始资产| U
关键风险：侧链安全由自己的节点负责，不继承以太坊L1安全。如果侧链节点作恶、桥漏洞，资产存在被盗风险——2022 年 Ronin 侧链桥被盗约 6.2 亿美元，桥是侧链安全链条上最薄弱的环节。

典型项目：Polygon PoS 是最著名的以太坊侧链，定期向以太坊提交检查点；Ronin（游戏专用）、Gnosis Chain 等亦属侧链。BSC 是拥有自有共识（PoSA）的独立 EVM 公链，通过官方桥与以太坊互通，严格来说是一条独立公链，通常被类比为侧链模式。

6. 总结

  • L1 = 银行总行，负责终极安全与资产结算，性能有限。
  • L2 = 总行下属高速营业厅，业务在本地高速处理，最终记账回总行；兼顾安全与性能，以太坊未来扩容主线。
  • 侧链 = 外部独立地方银行，可以和总行互通转账，但风控独立，性能强但安全降级。
业务选型建议：大额资产、高安全需求优先 L1/L2；高频小额游戏场景可考虑侧链，需要充分评估跨链桥风险。
