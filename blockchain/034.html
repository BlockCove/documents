1. 货币与银行体系：从央行到稳定币

传统金融

  • 货币 M0/M1/M2：现金 / 现金+活期 / +定期存款，央行控制发行
  • 央行 / 商业银行：央行印钱、定利率；商业银行放贷、创造存款
  • 利率：钱的价格，加息=收紧流动性，降息=放水
  • 通胀：货币超发导致物价上涨，法币购买力被稀释
  • 汇率：不同法币之间的兑换比率

Web3 对应

  • ETH / BTC：原生币 = 链上"黄金" / 数字现金，发行规则写在代码里
  • 稳定币：USDT/USDC（链下美元抵押）、DAI（链上超额抵押）、算法稳定币
  • Gas：以太坊上的"手续费"，用于支付矿工/验证者打包交易
  • 质押利率 / 借贷利率：Aave、Compound 上 USDT 存借利率，完全由市场供需自动定价
  • 算法货币政策：MakerDAO 的稳定费率（SF）= 链上央行利率，加息抑制 DAI 流通
关键对应：传统央行通过公开市场操作调节利率；MakerDAO 通过调节 Stability Fee（稳定费）调节 DAI 的铸造成本，本质是同一回事——只是决策者从美联储理事会变成了合约代码。

2. 资本市场：股票 / 债券 / 基金 / ETF

传统概念它是啥Web3 对应物
基础股票 公司所有权凭证，分红 + 股价涨跌 治理代币（如 UNI、AAVE）：协议所有权 + 投票权，但大多不分红（revenue share 是新趋势）
基础债券 借条，到期还本付息，有信用评级 RWA 代币化债券（如 MakerDAO 买的美国国债、Ondo 的 OUSG）：把现实债券上链
基础基金 / ETF 一篮子资产打包，由基金经理管理 指数产品（如 Bitwise 10 Crypto Index）、链上 Vault（Yearn、Set Protocol）：智能合约自动调仓
基础IPO 公司首次公开募股 ICO / IEO / IDO：首次代币发行；合规化后对应 STO（证券型代币发行）
基础市值 / 市盈率 股价×总股本；股价/每股盈利 Fully Diluted Valuation (FDV) / Market Cap；DeFi 用 TVL、费率年化来估值，不用 PE

3. 衍生品：期货 / 期权 / 永续合约

传统衍生品

  • 期货 Futures：约定未来某日按约定价格买卖，双方都有义务
  • 期权 Option：花权利金买一份权利而非义务（Call 买权 / Put 卖权）
  • 远期 Forward：场外非标期货，私下约定
  • 互换 Swap：交换未来现金流（利率互换、外汇互换）

加密衍生品

  • 永续合约 Perp：没有到期日的期货，靠资金费率（Funding Rate）让价格锚定现货；dYdX、GMX
  • 期权：Deribit 长期占据加密期权市场主导份额；链上有 Lyra、Aevo
  • 结构产品：自动做期权策略（如 Ribbon 卖出 covered call）
  • 杠杆 ETF 代币：LBTC2/3、LETF，内嵌再平衡

4. 交易与市场结构：CEX、DEX、AMM、订单簿

概念传统金融Web3本质
交易场所中心化交易所 纽交所、纳斯达克、上交所 CEX：Binance、OKX、Coinbase 公司撮合，用户把币托管给交易所
交易场所去中心化交易所 （传统没有对等物） DEX：Uniswap、PancakeSwap 智能合约撮合，用户自托管钱包
撮合方式订单簿 所有传统交易所的核心：买单/卖单排队 CLOB DEX：dYdX、Hyperliquid 挂单等待对手方
撮合方式做市商 Jump Trading、Jane Street、Citadel 高频报价赚差价 AMM（自动做市商）：x·y=k 算法自动定价 Uniswap V2：流动性池替代人工做市
流动性做市资金 做市商自有库存报价 LP 流动性提供者：用户把币存进池子，赚手续费 任何人都能当"做市商"
交易成本买卖价差 / 滑点 bid-ask spread 滑点 Slippage：大额交易价格偏离 池越深滑点越小
AMM 公式：Uniswap V2 核心就一行 x·y = k（池内两种币数量乘积恒定）。你卖 x 换 y，x 变多 → 价格自动上涨，本质是把做市商的报价规则写进了合约。

5. 信用与杠杆：抵押、清算、做多做空

传统信贷

  • 抵押贷款：房子抵押给银行，贷款 70% 估值
  • 保证金交易：券商给你融资/融券，维持保证金率
  • 强平：保证金不足 → 券商强制平仓
  • 做多 / 做空：看涨买现货；看跌借券卖出
  • 杠杆：借钱放大头寸，10 倍杠杆 = 价格反向 10% 爆仓

链上借贷

  • 超额抵押：Aave/Compound，抵押 200% 才能借出稳定币
  • 清算线 Liquidation Threshold：抵押率跌破阈值，合约自动拍卖抵押品
  • 清算人 Keeper：第三方机器人抢清算单，赚清算折扣
  • 闪贷 Flash Loan：一笔交易内借+还，无抵押，DeFi 独有
  • 杠杆挖矿：抵押 → 借稳定币 → 再存 → 再借，循环放大收益（同时放大爆仓风险）

6. Web3 特有黑话：DeFi / NFT / DAO / MEV

术语类比传统金融一句话解释
DeFi没有银行的银行体系用智能合约替代银行、券商、交易所，代码即规则，无需中心化机构托管
CeFi中心化加密金融（公司托管）Binance、Coinbase 这类中心化加密公司，用户把资产托管给平台
NFT收藏品 / 艺术品 / 会员卡链上唯一凭证，可代表艺术品、门票、游戏道具、版权
DAO没有 CEO 的公司 / 合作社持币者投票治理协议，链上执行提案
质押 Staking定期存款 + 股权投票锁定 ETH 参与 PoS 共识，赚区块奖励，锁仓期间不能随时取出
流动性挖矿 Yield Farming存贷+手续费+项目补贴把 LP 代币再质押进奖励池，拿项目代币奖励
Gas转账手续费 + 系统拥堵费以太坊每笔交易必须付的 ETH 手续费
MEV抢跑 / 交易排序获利验证者/搜索者通过重新排序、插入交易获利（三明治攻击、套利、清算）
空投 Airdrop用户拉新补贴项目方免费发代币给早期用户，换取留存和热度
Rug Pull跑路 / 卷款潜逃项目方拿走 LP 资金消失，DeFi 版"庞氏跑路"
稳定币脱锚 Depeg汇率失守USDT/DAI 偏离 1 美元，如 UST 从 1 美元跌到接近 0
桥 Bridge跨境资产搬运通道把资产从以太坊跨到 Solana/Arbitrum 等其他链

一句话总结

  • 同一套金融底层逻辑，两套实现：传统金融靠制度+信用+中介，Web3 靠代码+抵押+智能合约。
  • 稳定币 = 链上美元；DEX = 没有公司的交易所；借贷协议 = 没有柜员的银行；永续合约 = 没有到期日的期货。
  • 风险同源：杠杆、清算、信心崩塌、脱锚——传统金融踩过的坑，加密一个没少踩，只是跑得更快、更没有熔断。
本报告仅作概念科普，不构成任何投资建议。加密资产与衍生品波动极大，杠杆交易可能导致本金全部损失。
